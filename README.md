## Project Overview :rocket:
Pebble Promise was created as a final project for the **"Programming in Unreal Engine"** course.  
It is a **single-player, story-driven game** with a **third-person perspective**. 

The player takes on the role of a penguin exploring a small, cozy village. 
The game focuses on **interactions and environmental storytelling**.

The project was developed in **Unreal Engine using Blueprints**.

---

## Features :fire:
- Third-person character movement
- Exploration of a penguin village
- Dialogues with NPCs
- Collectible items
- Calm and cozy atmosphere inspired by narrative-driven games

---

## Installation :magic_wand:
1. **Clone the repository**  
   ```bash
   git clone https://github.com/Lesiiaa/PebblePromise.git
   ```
2. **Open the project in Unreal Engine**
3. **Open the level *Lvl_MainMenu***
4. **Run the game!**
